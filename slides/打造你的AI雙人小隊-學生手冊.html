學生講義｜打造你的 AI 雙人小隊

這堂課，你不用會寫程式。你要學的是一件更厲害的事：怎麼當一個 AI 小隊的小隊長。 上完課，你的電腦裡會住著兩個會自己分工、互相交接、一起把事情做完的 AI 夥伴。

一、先聽一個故事

有一位東華大學的老師，養了一組 AI 夥伴，他幫它們取了花蓮溪流的名字。這組隊伍一開始只有兩個人，後來越用越大，現在是四個人：

  • 洄瀾——組長，負責想清楚要做什麼、分配工作、最後把關。
  • 立霧——隊員，手很快，擅長畫圖、上網查資料、直接動手改東西。
  • 秀姑巒——隊員，擅長同時開很多分身、把大任務拆成小塊一起查、一起做。
  • 木瓜溪——隊員，負責便宜又大量的粗篩工作，先幫大家把資料篩過一輪。

奇妙的地方是：這四個 AI 從來不直接講話。

它們共用同一個資料夾。組長把今天要做的事寫成一張紙條，放進一個叫 inbox（收件匣）的格子；隊員打開資料夾看到紙條，做完之後把成品放進 outbox（寄件匣），再留一行字：「我做完了，這裡要注意。」組長回來收，檢查好，交給老師。

聽起來像不像一間小公司？對——這就是你這堂課要親手打造的東西，只是縮小成兩個人。

二、你會做出什麼？（成品長這樣）

你會在自己的電腦上養出兩個 AI 夥伴：

角色 跑在哪個 AI 上 工作 名字（範例）
領隊 OpenAI Codex 聽你下指令、想計畫、把任務分給隊員、最後檢查（還會「電腦操作」當你的雙手——進階玩法） 例如「洄瀾」
隊員 Google Antigravity（agy） 接任務、實際動手做、把成品交回去 例如「太魯閣」

它們透過一個共用資料夾互相傳紙條，你只要對領隊說一句話，就能看著兩個 AI 自己把事情接力完成。

這兩個夥伴是你的——名字、個性、專長你自己設計。 設定時 AI 會一題一題訪問你（要叫什麼、什麼個性、想拿來做什麼），你自己決定；懶得想就答「都好」，用預設名：領隊洄瀾、隊員太魯閣（都是花蓮的名字——洄瀾是花蓮的古名、太魯閣是那座有名的峽谷；領隊借用老師團隊那位統籌者洄瀾的名字）。名字也可以換成你家鄉的河、山、海，或任何你喜歡的——有名字、有個性，它才像一個「夥伴」，不是一個冷冰冰的工具。

三、它們到底怎麼「對話」？（最重要的觀念）

很多人以為「讓兩個 AI 合作」要很高深的技術。其實核心觀念簡單到不可思議：

它們不直接對話，而是共用一個資料夾、互相留紙條。

想像一間辦公室裡有三個格子：

       共用資料夾
   ┌─────────────────────┐
   │  📥 inbox（收件匣）  │ ← 領隊把「要做的任務」放這
   │  📤 outbox（寄件匣） │ ← 隊員把「做好的成品」放這
   │  📚 shared（共用區） │ ← 兩個人都會看的長期資料
   └─────────────────────┘

流程就像接力賽：

  1. 你（小隊長）對領隊說：「幫我把這次花蓮小旅行排成三天兩夜行程。」
  2. 領隊想一下，把任務寫成紙條丟進 inbox，然後跟你說：「派好了，去叫隊員開工吧。」
  3. 你轉頭叫隊員：他看到紙條，動手查、整理，把成品放進 outbox，跟你說：「做好了，請你回去叫領隊檢查。」
  4. 你回去叫領隊收成品、檢查、潤飾，交給你。

你就像一個小隊長，在兩個夥伴之間傳遞棒子——這樣整個團隊你看得到、也指揮得到。

想更省事？也可以叫領隊用「全自動模式」：它自己把整件事做完、檢查好、直接回報你，你只跟領隊講話就好（這版是領隊一個人完成；要它自動叫隊員是進階玩法，見安裝指南「模式三」）。手動接力（你親自傳棒）和全自動兩種玩法課堂都會教，你自己選。

這就是「多代理人協作」(multi-agent collaboration)——2026 年最重要的 AI 技能之一。

四、那一份「團隊公約」是靈魂

兩個 AI 怎麼知道自己是誰、該做什麼、紙條放哪裡？

靠資料夾裡一份叫 AGENTS.md 的文字檔——可以把它想成團隊的「員工守則」。每個 AI 一開機，第一件事就是讀這份守則，於是它就知道：

  • 我是領隊還是隊員？
  • 我的個性、講話風格是什麼？
  • 任務紙條放哪個格子、成品放哪個格子？
  • 交接的時候要留什麼話？

你不用從零寫這份守則——本教材的 範本團隊/ 資料夾裡已經幫你準備好範本，你只要改名字、改個性就能用。

五、你在這堂課真正學到的東西

你以為你在「裝軟體」，其實你在練三個未來很值錢的能力：

  1. 把一件大事拆成小任務——這是管理的本質。
  2. 把需求講清楚——AI 做得好不好，七成看你問得清不清楚。
  3. 指揮一個團隊、檢查成果——你是小隊長，不是工人。

單純做重複性的程式編碼，可能慢慢被 AI 接手；但「懂得拆解大任務、指揮一群 AI 協作的人」永遠搶手。 這堂課練的，就是這個帶得走的能力。

六、小隊長大了會怎樣？（真實團隊的經驗）

前面說的那組「洄瀾／立霧／秀姑巒／木瓜溪」，一開始也只有兩個人，跟你今天要裝的一樣。後來老師發現：任務一多，「一個人包辦全部」反而卡關——於是照任務會在哪裡出問題，陸續加了新夥伴進來。

這裡有一個真實團隊摸出來、很重要的心得：

派工要看「這件事最容易在哪裡出錯」，不是看「哪個工具比較新、比較潮」。

舉例： - 要判斷、拍板的事（這個方向對不對？可以交出去了嗎？）——交給想得比較遠、負責把關的那位。 - 要快、動手做的事（把這個畫出來、把這段改掉）——交給手快的那位。 - 要廣搜、一次查很多、怕漏東西的事——交給擅長同時拆很多分身查的那位。

你今天的雙人小隊，其實就是這個道理的入門版：領隊想清楚、拆任務、把關，隊員動手做。以後如果你想加第三個、第四個夥伴，別急著照「這個 AI 工具比較厲害」去派工，先問自己：這件事最容易在哪裡出包？ 想清楚這點，你的小隊才會越加越大、不會越加越亂。

安裝設定指南｜把你的 AI 雙人小隊裝起來

給東華大學通識課的同學。不用寫程式，而且這版以桌面 app（滑鼠操作）為主——像平常用 app 一樣點一點就好。 精神：能交給 AI 做的就交給 AI 做（設定資料夾、甚至幫你設計角色）。你只負責「登入自己的帳號」和「下指令」。 全程約 20–30 分鐘。桌面步驟經隊員/領隊查官方文件確認過。

最快的開始方式：讓 AI 讀這份指南、帶你裝

  • 方式一（最省事）：讓 AI 讀整包教材、手把手帶你。 把這門課的 GitHub 網址（老師會給）或這個資料夾交給你手邊任何一個 AI，跟它說：

    「請讀這個 repo 裡的 02_安裝設定指南.md 和 AGENTS.md，一步一步幫我把『AI 雙人小隊』裝起來。需要我登入帳號或做決定時，停下來問我。全程繁體中文台灣用語。」 注意：網頁版 AI（ChatGPT／Gemini）沒有手、不能直接操作你的電腦，它會當「導航」，把該按的、該貼的告訴你，你照著點就好。

  • 方式二：自己照下面步驟做。

核心觀念：一個「專案資料夾」，兩個夥伴都開它 🔑

你的小隊住在一個資料夾裡——這就是你的「專案資料夾」。 領隊和隊員都要打開「同一個這個資料夾」，才傳得到紙條、才合作得起來。全班最常卡的就是兩邊開到不同資料夾。

📂 先把「我的小隊」資料夾準備好（挑一種方式）

⚠️ 重要：等一下你電腦會有兩個資料夾，用途不同、別搞混！ - 教材資料夾（解壓縮得到的 ai-agent-team-course…）＝你的課本。要複製咒語、看講義時，用瀏覽器或記事本打開裡面的檔（如 04_給AI的指令包.md）。 - 我的小隊＝你的專案資料夾，兩個 AI 夥伴住的地方。Codex 和 Antigravity 兩個 app 都要打開這一個。

方式 A（電腦教室標準・推薦）——全程滑鼠、不用終端機、不用 GitHub 帳號 1. 下載教材 ZIP：打開這個連結（老師也會在課程網站給）： https://github.com/cwstedctw/ai-agent-team-course/archive/refs/heads/master.zip。

💡 放哪都行，但別放在會被雲端同步的地方（桌面、OneDrive、iCloud 同步的資料夾）——同步會鎖住檔案，害 AI 寫入時出怪錯。放一個一般的本機資料夾最穩（例如在 C 槽底下自己建一個）。 2. 解壓縮：得到一個 ai-agent-team-course-master 資料夾（這就是「教材資料夾」，也是你這門課的工作資料夾，東西都放它裡面）。 3. 進去找到 範本團隊 資料夾，就在這裡複製一份、改名為 我的小隊（這樣教材和你的小隊都在同一個資料夾裡，好整理）。 4. 完成！接著照 Part A，在兩個 app 裡選這個 我的小隊（路徑 ai-agent-team-course-master/我的小隊）——選資料夾本來就是用這些 app 的第一步。

方式 B（自帶筆電・進階）——讓領隊 Codex 自動幫你建 電腦已裝好 Git 的同學：裝好 Codex 後，先用 Select a project 選一個現成、不被雲端同步的資料夾當起點（例如在 C 槽自己建一個空資料夾），模式選 Local，再貼 04 的咒語 0，讓領隊自動 clone 教材、在那個資料夾裡建好 我的小隊；建完關掉 Codex 重開、改選它印出的 我的小隊（細節與防呆見 04 咒語 0）。沒裝 Git 的別貼咒語 0，直接走方式 A 最快；想裝起來用 GitHub 的，看下面這段。

🧰 進階加裝：Git ＋ GitHub CLI（想直接用 GitHub 的同學） 方式 A 的 ZIP 下載完全不需要這些。但如果你想用一行指令直接抓教材、或之後把自己的成品推上 GitHub，裝這兩個會順很多（需要一個免費 GitHub 帳號）： - Git（版本控制的基礎工具） - 🪟 Windows：winget install --id Git.Git -e，或到 https://git-scm.com/download/win 下載、一路下一步。 - 🍎 Mac：終端機跑 xcode-select --install（內含 git），或 brew install git。 - GitHub CLI（指令 gh）（在終端機操作 GitHub） - 🪟 Windows：winget install --id GitHub.cli，或到 https://cli.github.com 下載。 - 🍎 Mac：brew install gh。 - 裝完開一個新的終端機，跑 gh auth login，照畫面用瀏覽器登入你的 GitHub。之後就能一行抓整包教材： gh repo clone cwstedctw/ai-agent-team-course 🪟 Windows 小提醒：裝完 CLI 要把終端機全部關掉重開，PATH 才會生效（用方式 A 完全不會遇到）。

Part A：兩個 app 都打開「我的小隊」——先請領隊 Codex 就位

這門課裡 Codex 是領隊洄瀾，先讓它就位、帶起整個小隊。

  1. 裝 Codex app（官方桌面版），打開後用你自己的 ChatGPT 帳號登入（登入你自己來）。
  2. 點 Select a project／選擇專案資料夾，選你剛準備好的 我的小隊 資料夾（注意是選 我的小隊，不是外層的教材資料夾）。

    ⚠️ Windows 防呆：彈出的「選擇資料夾」視窗只顯示資料夾、把檔案（如 AGENTS.md）藏起來。正常！確認選中 我的小隊，點右下角 「選擇資料夾」 即可。

  3. 確認畫面顯示 Local；貼咒語 1：請先讀這個資料夾的 AGENTS.md，告訴我你的身分。 → 它會認出自己是領隊洄瀾，並印出專案資料夾完整路徑（記住這個路徑，等一下隊員要開同一個）。

🛠️ 進階（會用終端機的人才需要）：也可以在 我的小隊 裡直接跑 codex。一般同學用桌面 app 就好。

Part B：讓領隊設計你的小隊

在 Codex（領隊洄瀾）裡，貼這句（複製 04 咒語 2），它會一題一題問你（名字、個性、想做什麼），幫你寫好 AGENTS.md 與人格檔，並把專案資料夾路徑印出來。

懶得想就每題答「都好」，用預設：領隊洄瀾、隊員太魯閣。

把「設計小隊」交給領隊問你，就是「讓 AI 幫你設定」的精神。

Part C：讓隊員就位（Antigravity 桌面版 開「同一個」專案資料夾）

這門課裡 Antigravity 是隊員太魯閣。

  1. 裝 Antigravity 桌面版：到 https://antigravity.google/download 下載安裝（認明桌面版，不是開發者 IDE 版）。
  2. 打開它，點「用 Google 帳號登入」（免費 Google 帳號就行，登入你自己來）。
  3. 在 Antigravity 裡打開剛剛那個一模一樣的專案資料夾（領隊在 Part A 印出來的 我的小隊）。
  4. 對它說一句：請先讀這個資料夾的 AGENTS.md，告訴我你的身分。 → 它會認出自己是隊員太魯閣。

🛠️ 進階：也可用 CLI——在 我的小隊 資料夾裡跑 agy，進入後輸入 /add-dir . 把這個資料夾加進來。

Part D：開工！選一種模式，下第一個任務

你是小隊長。開工前，先跟領隊講要用哪種模式：

模式一：手動接力（預設，看得見每一棒）

  1. 跟領隊（Codex）說：這次用手動模式。幫我做一份花蓮一日遊景點清單，三個點各一句。拆好任務寫進 inbox 後叫我去請隊員。
  2. 領隊把任務寫進 inbox，叫你去找隊員。
  3. 你切到 Antigravity（隊員）：看 inbox 接任務、做完放 outbox、叫我回去找領隊。
  4. 你回到 Codex（領隊）：收 outbox、檢查、給我總結。

🎉 你剛當了一次小隊長，親手指揮兩個 AI 接力完成一件事——全程只動嘴、沒寫半行程式。

模式二：全自動（省事）

跟領隊說：這次用自動模式，幫我把整件事跑完、檢查好、直接回報我。

小提醒：這是「領隊一個人」把事做完（單人全自動）。要讓領隊自動叫隊員做到「雙人全自動」，需要進階的 agy CLI 或 Computer Use（見模式三）；課堂用單人全自動體會「交給 AI」就夠了。

模式三（進階示範）：領隊用 Computer Use 自己跑完手動接力 ⭐

領隊（Codex）能用「電腦操作（Computer Use）」當你的雙手——自己切到隊員 Antigravity 的視窗、貼指令、再回收檢查，把手動接力自動演一遍給你看。做法見 04 咒語 9。

⚠️ 需要較新的 Windows／Mac；執行時它會接管你的滑鼠鍵盤、佔住前景（你會看著它自己動）。不是每台機器都跑得動，當示範用，不是基本盤。 另需先到 Codex 設定 → Computer use → 控制 → 打開「任何應用程式（讓 Codex 控制你電腦上的應用程式）」 才跑得動（見 04 咒語 9）。 💡 心理建設：看到滑鼠鍵盤自己動，是 AI 在工作、不是中毒也不是被駭，別緊張——把手離開鍵盤，看它表演就好。

兩三種都玩一次，感受差別：手動＝你掌控、看得見；自動＝快、交給 AI；Computer Use＝看 AI 替你動手。 這就是「要不要讓人插手」——AI 時代最重要的判斷之一。

常見卡關

症狀 多半是 解法
隊員看不到領隊放的紙條 兩個 app 開到不同資料夾 各自叫 AI「印出你現在的專案資料夾完整路徑」，兩邊對到一模一樣
Codex（領隊）登入失敗 校園網路（proxy）或選錯帳號 換個網路再試；登入頁選你自己的 ChatGPT 帳號；被用量限制就換帳號或找老師
領隊在手動模式自己跑去做隊員的活 沒講清楚模式 開工第一句明講「用手動模式，寫完 inbox 就停、叫我去找隊員」
Computer Use 跑不動 機器較舊或系統不支援 沒關係，它本來就是進階示範；改用模式一手動接力即可

📌 給 AI 與老師看的技術備註（學生可跳過）

這段給「幫忙設定的 AI」和老師看——把會影響順不順的細節一次講清。學生不必懂。

角色與環境 - 領隊洄瀾＝Codex（跑在 codex）；隊員太魯閣＝Antigravity（跑在 agy）。桌面為主：領隊用 Codex app「Select a project」開專案資料夾、隊員用 Antigravity 桌面版開同一個資料夾。CLI 是進階/備援。 - 兩個 agent 不直接對話，靠專案資料夾的 workspace/inbox、outbox、shared 傳檔；兩邊必須是同一個專案資料夾。 - 三種模式：手動接力（預設，agent 不互相直呼、棒子交回小隊長）、全自動、Computer Use 示範（進階）。

安裝與帳號 - 領隊 Codex：官方桌面 app＋VS Code/Cursor/Windsurf 擴充（app、ide），會在動工前讀 AGENTS.md（agents-md）。用 ChatGPT 帳號登入（各方案含免費都能用、只差用量）；校園 proxy 攔 TLS 可能讓 OAuth 失敗，課前在教室網路試一次。CLI 進階：Windows irm https://chatgpt.com/codex/install.ps1 | iex、Mac curl -fsSL https://chatgpt.com/codex/install.sh | sh。 - 隊員 Antigravity：桌面版（https://antigravity.google/download），任何 Google 帳號（含免費）登入。CLI 進階：Windows irm https://antigravity.google/cli/install.ps1 | iex、Mac curl -fsSL https://antigravity.google/cli/install.sh | bash（裝到使用者資料夾、免系統管理員）。 - 🪟 Windows 走 CLI 時：裝完任何 CLI 要把所有終端機關掉重開，PATH 才生效（用桌面 app 不會遇到）。

Computer Use（模式三，進階） - Codex app（v26.527 起）在 Windows 可「看畫面、點按鈕、打字」操作桌面程式（Computer Use 文件）。⚠️ Windows 上跑在使用中的桌面、不能背景跑，執行時接管前景滑鼠鍵盤；手機遠端管理那套要 Win11 build 26100＋NPU。所以核心課程不依賴它，只當示範。

AGENTS.md／身分 - codex 會自動讀專案根目錄的 AGENTS.md（OpenAI 官方文件明載），開機自動認身分。Antigravity 不保證會自動讀，所以隊員第一句一律明確要它「先讀這個資料夾的 AGENTS.md」（Part C 步驟 4／咒語都含這句）。沒有用 .agents/ 子資料夾；若要讓 Antigravity 自動套用，可在它的 Rules 介面把 AGENTS.md 設為 Always On。 - 保險起見可叫 agent 第一句報到時「印出專案資料夾完整路徑」，確認兩邊同一個。

機制說明：兩個 agent 透過 inbox／outbox 互傳紙條的整條協作鏈，已驗證可正常運作。inbox／outbox 檔名建議「日期在前＋簡述」（如 任務-20260701-花蓮一日遊清單.md），成品一多才排得出順序——範本團隊的 workspace 各資料夾 README 已寫明。

進階（程度好的學生）：想擴編第三個隊員、或幫小隊裝一個「記住學過的東西」的 shared/log.md，見 04_給AI的指令包.md 咒語 10、11。

給 AI 的指令包｜把事情交給 AI 做

用法：下面每段是一個「咒語」。整段複製，貼進你正在用的 AI（領隊洄瀾＝Codex、隊員太魯閣＝Antigravity，桌面 app 或終端機都行），按 Enter，請它幫你做。 咒語裡的「洄瀾／太魯閣」是預設名，你改過就跟著換。你（學生）＝小隊長。 ⚠️ 咒語 0／2／5／7 需要 AI 能讀寫你電腦上的專案資料夾，要用本機的 Codex／Antigravity app；網頁版 AI（ChatGPT／Gemini 網頁）沒有手、只能當「導航」教你怎麼點。

咒語 0：請領隊把我的小隊裝起來（方式 B・進階，貼給剛裝好＋登入的 Codex）⭐

給「自帶筆電、電腦已裝 Git」的同學。電腦教室或沒裝 Git 的，用指南「方式 A」下載 ZIP 最快、不必貼這條。 貼給領隊 Codex（先 Select a project 選一個現成、不被雲端同步的資料夾當起點，模式選 Local，再貼本咒語）。桌面版 Antigravity 仍你自己裝（指南 Part C）。

請幫我把這門課的「AI 雙人小隊」設定好。一步一步做，每跑一個指令前先用白話說你要做什麼；
看到要我「允許執行指令」的提示，我確認後會按允許：
1. 先印出你現在打開的資料夾（工作目錄）完整路徑給我看。確認這個路徑「不含 OneDrive、Desktop、桌面、iCloud」；
   如果有，先停下來提醒我，引導我換到一個不被雲端同步的資料夾再繼續（雲端同步會鎖檔、害你等下寫檔出錯）。
2. 檢查我這台有沒有 git（git --version）。
   如果「沒有」git，先停下來叫我改走指南「方式 A」下載 ZIP，不要自己幫我下載（現場自動下載解壓變數太多）。
3. 有 git → 在目前這個資料夾執行 git clone https://github.com/cwstedctw/ai-agent-team-course.git
4. 找出 clone 出來、裡面看得到「範本團隊」的那個教材資料夾，把「範本團隊」整包複製一份、改名為「我的小隊」（放在同一個地方就好）。
   若已經有「我的小隊」，先停下來問我：要覆蓋、還是改名成「我的小隊-2」。
5. 把「我的小隊」的完整路徑印出來給我（兩個 app 等一下都要開這個資料夾）。
做完用白話告訴我下一步：關掉你、再打開、Select a project 選「我的小隊」。需要我登入或決定時停下來問我。全程繁體中文台灣用語。

咒語 1：報到＋確認環境＋印出專案資料夾路徑

貼給領隊洄瀾（Codex）。

你是領隊。請先讀這個資料夾的 AGENTS.md，跟我（小隊長）報到一句，
把這個專案資料夾的完整路徑印出來給我（等一下隊員要開同一個資料夾），
並確認你能讀寫 workspace/inbox、outbox、shared 三個格子。
遇到要我登入帳號或做決定時，停下來告訴我。全程繁體中文台灣用語。

咒語 2：讓 AI 訪談我、設計我的小隊 ⭐

貼給領隊洄瀾（Codex）。

我想設計一個我自己的 AI 雙人小隊。請你「一題一題問我」，問完幫我把設定寫進這個專案資料夾的
AGENTS.md、領隊人格檔（領隊-洄瀾.md）、隊員人格檔（隊員-太魯閣.md）——改名字時只改檔案內容、
保留原檔名不變，免得資料夾長出一堆多餘的人格檔：
1. 領隊要叫什麼名字、什麼個性？
2. 隊員要叫什麼名字、什麼個性？
3. 我最想用這個小隊做什麼（例如排旅遊行程、做報告、整理筆記）？
規則：跑在 codex 上的是領隊、跑在 agy 上的是隊員；兩人靠 workspace 底下的 inbox、outbox、shared
傳紙條；預設「手動接力」模式（可切「全自動」）；全程繁體中文、自然的台灣口語。
我若答「都好」，就用預設：領隊洄瀾、隊員太魯閣。先問我第一題。

咒語 3：幫我把專案資料夾從零建起來（沒拿到範本時）

請在目前這個資料夾裡，建立一個 AI 雙人小隊的骨架：
一份 AGENTS.md（寫明：跑在 codex 上的是領隊、跑在 agy 上的是隊員，兩人靠 workspace/inbox、outbox、
shared 傳紙條；預設「手動接力」模式、可切「全自動」；全程台灣用語），一份領隊人格檔、一份隊員人格檔，
以及 workspace/inbox、workspace/outbox、workspace/shared 三個資料夾。
建好後把這個資料夾的完整路徑印出來，並用白話告訴我每個檔案做什麼。繁體中文台灣用語。

咒語 4：報到＋印出專案資料夾路徑（兩個 AI 各貼一次）

請先讀這個資料夾的 AGENTS.md，認出你是領隊還是隊員，跟我（小隊長）報到一句，
並把這個專案資料夾的完整路徑印出來給我，讓我確認兩個 AI 對著同一個資料夾。

咒語 5：選模式 ＋ 下第一個任務（給領隊 Codex）

這次用「手動接力」模式（你拆好任務寫進 workspace/inbox 後就停下來，叫我去請隊員開工，
不要自己叫隊員）。任務：幫我做一份花蓮一日遊景點清單，三個點、每點一句，要好看清楚。
請先把任務拆好寫進 workspace/inbox，再告訴我下一步去叫誰。全程繁體中文。

想省事？把第一行改成「這次用全自動模式（你自己把整件事跑完、檢查好、直接回報我）」。

咒語 6：叫隊員開工（手動接力模式時，貼給隊員 Antigravity）

你是隊員。請看 workspace/inbox 有沒有領隊派的任務；有的話照著做，
做完把成品放 workspace/outbox 並留一行交接，然後叫我回去請領隊檢查。先回我一句你準備好了。

咒語 7：成品出來了，幫我檢查（給領隊 Codex）

隊員已經把成品放在 workspace/outbox 了。請你（領隊）打開來檢查：
有沒有照需求做、哪裡可以更好，需要的話幫我潤飾，最後用三句話跟我總結。繁體中文。

咒語 8：兩邊對不上（隊員看不到領隊的紙條）

我想讓兩個 AI 用同一個專案資料夾協作，但隊員看不到領隊放的檔案。
請幫我診斷：把你現在的專案資料夾完整路徑印出來，
再告訴我怎麼確認另一邊是不是同一個資料夾、以及怎麼對齊。繁體中文、一步一步、像對長輩說話。

咒語 9：高階進階玩法——用 Computer Use 自動跑手動接力（演示手動模式自動化）⭐

貼給領隊洄瀾（Codex，支援 Computer Use／電腦操作）。 這條咒語示範讓領隊扮演「學生的雙手」，在手動模式下自己切換視窗、貼指令並完成完整的手動接力驗收！ ⚠️ 需要較新的 Windows／Mac；執行時會接管你的滑鼠鍵盤、佔住前景。當示範用，不是基本盤。 前提（一定要先開）：到 Codex 設定 → Computer use（管理 Codex 如何使用你電腦上的其他應用程式）→ 控制 → 打開「任何應用程式：讓 Codex 控制你電腦上的應用程式」 這個開關；沒開，咒語 9 不會動。Mac 還要到系統設定給 Codex「螢幕錄製／輔助使用」權限。 看到滑鼠鍵盤自己動，是 AI 在工作、不是中毒，別緊張。

請用 Computer Use 幫我操作 Antigravity（隊員）視窗，完成一次手動接力流程。

分工：
- 你（領隊 Codex）：拆任務、寫派工紙條、最後檢查。
- 隊員 Antigravity：讀取派工紙條、完成成品、寫入 outbox。

任務主題：台北親子半日遊

流程：
1. 你先把任務拆好，寫入 workspace/inbox/task.md。
2. 你再用 Computer Use 操作 Antigravity 視窗，把以下指令貼進去並送出：
   「請讀取 workspace/inbox/task.md，照任務完成成品，放進 workspace/outbox/，並留下 workspace/outbox/handoff.md 交接說明。完成後請停下來，只回報『已完成，可請領隊檢查』。」
3. 等 Antigravity 完成後，你讀取 workspace/outbox 的成品與 handoff.md。
4. 你檢查成品是否符合 workspace/inbox/task.md 的規格。
5. 你最後把審查結果回報給我。

交付格式：Markdown 表格
表格欄位包含：時間、地點、附近捷運站、活動內容、適合年齡、雨天備案、資料來源

輸出檔案：
- workspace/outbox/parent-child-halfday.md
- workspace/outbox/handoff.md

咒語 10：加第三個隊員——派工看風險，不看工具（進階）⭐

貼給領隊（Codex）。這條不裝新軟體，只是把小隊從兩人擴編成三人（或更多）的思考練習。

我想把小隊擴編成三人（或更多）。請你（領隊）先幫我想清楚，不要一開始就動手改檔：
1. 問我：我最近常派給小隊做的任務裡，有哪幾種？各自最容易在哪裡出包
   （例如：需要判斷/拍板？需要快、動手做？還是需要一次查很多、怕漏東西？）。
2. 依照我的回答，建議第三個隊員該負責哪一種「風險」，而不是建議某個特定工具比較潮。
3. 等我確認分工後，才幫我在這個資料夾新增一份人格檔（仿照領隊-洄瀾.md／隊員-太魯閣.md的格式），
   並在 AGENTS.md 補上這位新隊員的角色與派工原則。
全程繁體中文台灣用語，改檔前先講你要做什麼。

咒語 11：幫小隊裝上「記憶」——開機接得上進度（進階）⭐

貼給領隊或隊員任一位。這條讓小隊學會「記住學過的東西」，不用你每次重講一遍。

請在 workspace/shared/ 底下建一個 log.md（如果還沒有），格式如下：
- 每行一條，開頭是日期，例如：`- [2026-07-01] 小隊長平常喜歡先看清單再看細節，回報時清單放最前面`。
- 這份檔案專門記「我學到的、小隊長的習慣、常卡關的地方、新加的規則」，不是流水帳。
建好之後，把它加進 AGENTS.md 裡：提醒以後開機除了讀 AGENTS.md，也要順手翻一下 shared/log.md 最後幾行，
接上小隊長之前教過的事。今天如果有什麼想讓小隊記住的（例如我的個性、我常犯的錯、我喜歡的格式），
先問我一次，我答完你就先記一條進去當示範。全程繁體中文台灣用語。
