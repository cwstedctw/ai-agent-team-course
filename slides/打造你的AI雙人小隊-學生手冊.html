學生講義｜打造你的 AI 雙人小隊

這堂課，你不用會寫程式。你要學的是一件更厲害的事：怎麼當一個 AI 小隊的小隊長。 上完課，你的電腦裡會住著兩個會自己分工、互相交接、一起把事情做完的 AI 夥伴。

一、先聽一個故事

有一位東華大學的老師，養了一組 AI 夥伴，他幫它們取了花蓮溪流的名字：

  • 洄瀾——組長，負責想清楚要做什麼、分配工作、最後把關。
  • 立霧——隊員，手很快，擅長畫圖、上網查資料。
  • 秀姑巒——隊員，擅長同時開很多分身、把大任務拆成小塊一起做。

奇妙的地方是：這三個 AI 從來不直接講話。

它們共用同一個資料夾。組長把今天要做的事寫成一張紙條，放進一個叫 inbox（收件匣）的格子；隊員打開資料夾看到紙條，做完之後把成品放進 outbox（寄件匣），再留一行字：「我做完了，這裡要注意。」組長回來收，檢查好，交給老師。

聽起來像不像一間小公司？對——這就是你這堂課要親手打造的東西，只是縮小成兩個人。

二、你會做出什麼？（成品長這樣）

你會在自己的電腦上養出兩個 AI 夥伴：

角色 跑在哪個 AI 上 工作 名字（範例）
領隊 OpenAI Codex 聽你下指令、想計畫、把任務分給隊員、最後檢查（還會「電腦操作」當你的雙手——進階玩法） 例如「洄瀾」
隊員 Google Antigravity（agy） 接任務、實際動手做、把成品交回去 例如「太魯閣」

它們透過一個共用資料夾互相傳紙條，你只要對領隊說一句話，就能看著兩個 AI 自己把事情接力完成。

這兩個夥伴是你的——名字、個性、專長你自己設計。 設定時 AI 會一題一題訪問你（要叫什麼、什麼個性、想拿來做什麼），你自己決定；懶得想就答「都好」，用預設名：領隊洄瀾、隊員太魯閣（都是花蓮的名字——洄瀾是花蓮的古名、太魯閣是那座有名的峽谷；領隊借用老師團隊那位統籌者洄瀾的名字）。名字也可以換成你家鄉的河、山、海，或任何你喜歡的——有名字、有個性，它才像一個「夥伴」，不是一個冷冰冰的工具。

三、它們到底怎麼「對話」？（最重要的觀念）

很多人以為「讓兩個 AI 合作」要很高深的技術。其實核心觀念簡單到不可思議：

它們不直接對話，而是共用一個資料夾、互相留紙條。

想像一間辦公室裡有三個格子：

       共用資料夾
   ┌─────────────────────┐
   │  📥 inbox（收件匣）  │ ← 領隊把「要做的任務」放這
   │  📤 outbox（寄件匣） │ ← 隊員把「做好的成品」放這
   │  📚 shared（共用區） │ ← 兩個人都會看的長期資料
   └─────────────────────┘

流程就像接力賽：

  1. 你（小隊長）對領隊說：「幫我把這次花蓮小旅行排成三天兩夜行程。」
  2. 領隊想一下，把任務寫成紙條丟進 inbox，然後跟你說：「派好了，去叫隊員開工吧。」
  3. 你轉頭叫隊員：他看到紙條，動手查、整理，把成品放進 outbox，跟你說：「做好了，請你回去叫領隊檢查。」
  4. 你回去叫領隊收成品、檢查、潤飾，交給你。

你就像一個小隊長，在兩個夥伴之間傳遞棒子——這樣整個團隊你看得到、也指揮得到。

想更省事？也可以叫領隊用「全自動模式」：它自己叫隊員、自己收尾，你只跟領隊講話就好。手動接力（你親自傳棒）和全自動兩種玩法課堂都會教，你自己選。

這就是「多代理人協作」(multi-agent collaboration)——2026 年最重要的 AI 技能之一。

四、那一份「團隊公約」是靈魂

兩個 AI 怎麼知道自己是誰、該做什麼、紙條放哪裡？

靠資料夾裡一份叫 AGENTS.md 的文字檔——可以把它想成團隊的「員工守則」。每個 AI 一開機，第一件事就是讀這份守則，於是它就知道：

  • 我是領隊還是隊員？
  • 我的個性、講話風格是什麼？
  • 任務紙條放哪個格子、成品放哪個格子？
  • 交接的時候要留什麼話？

你不用從零寫這份守則——本教材的 範本團隊/ 資料夾裡已經幫你準備好範本，你只要改名字、改個性就能用。

五、你在這堂課真正學到的東西

你以為你在「裝軟體」，其實你在練三個未來很值錢的能力：

  1. 把一件大事拆成小任務——這是管理的本質。
  2. 把需求講清楚——AI 做得好不好，七成看你問得清不清楚。
  3. 指揮一個團隊、檢查成果——你是小隊長，不是工人。

寫程式會被 AI 取代，但「會指揮 AI 的人」不會。 這堂課練的就是後者。

安裝設定指南｜把你的 AI 雙人小隊裝起來

給東華大學通識課的同學。不用寫程式，而且這版以桌面 app（滑鼠操作）為主——像平常用 app 一樣點一點就好。 精神：能交給 AI 做的就交給 AI 做（設定資料夾、甚至幫你設計角色）。你只負責「登入自己的帳號」和「下指令」。 全程約 20–30 分鐘。桌面步驟經隊員/領隊查官方文件確認過。

最快的開始方式：讓 AI 讀這份指南、帶你裝

  • 方式一（最省事）：讓 AI 讀整包教材、手把手帶你。 把這門課的 GitHub 網址（老師會給）或這個資料夾交給你手邊任何一個 AI，跟它說：

    「請讀這個 repo 裡的 02_安裝設定指南.md 和 AGENTS.md，一步一步幫我把『AI 雙人小隊』裝起來。需要我登入帳號或做決定時，停下來問我。全程繁體中文台灣用語。」 注意：網頁版 AI（ChatGPT／Gemini）沒有手、不能直接操作你的電腦，它會當「導航」，把該按的、該貼的告訴你，你照著點就好。

  • 方式二：自己照下面步驟做。

核心觀念：一個「專案資料夾」，兩個夥伴都開它 🔑

你的小隊住在一個資料夾裡——這就是你的「專案資料夾」。 領隊和隊員都要打開「同一個這個資料夾」，才傳得到紙條、才合作得起來。全班最常卡的就是兩邊開到不同資料夾。

📂 「我的小隊」資料夾怎麼來？——交給領隊 Codex 建

別擔心怎麼下載、怎麼複製、怎麼改名。等一下你裝好領隊 Codex、登入，貼一句話（咒語 0）給它，它就會自動幫你：下載這門課的教材、建好你桌面的「我的小隊」資料夾、檢查環境，最後把資料夾路徑印給你。你只要照 Part A 做。

這就是這門課的精神：能交給 AI 做的就交給 AI 做。 你負責登入帳號、下指令；繁瑣的下載與設定，交給領隊。

Part A：先請領隊就位、幫你把小隊建起來（Codex app）

這門課裡 Codex 是領隊洄瀾——它能「電腦操作」、也能幫你跑下載與設定，所以讓它先就位、帶起整個小隊。

  1. 裝 Codex app（官方桌面版），打開後用你自己的 ChatGPT 帳號登入（登入你自己來）。
  2. 先讓它開你的桌面當臨時工作區：點 Select a project／選擇專案資料夾，選「桌面 Desktop」（等一下小隊建好再換過去）。
  3. 貼「咒語 0」（在 04_給AI的指令包.md）給它、送出。它會自動：用 gh repo clone cwstedctw/ai-agent-team-course 下載教材、把裡面的 範本團隊 複製成你桌面的 我的小隊、檢查環境（含 Antigravity 的 agy），最後印出 我的小隊 的完整路徑。

    過程中要你登入或做決定，它會停下來問你。若它說你電腦沒有 gh，照它的話做（它會改用 git clone 或教你裝）。桌面版 Antigravity 還是你自己裝（Part C），Codex 只幫你把專案建好。

  4. 關掉 Codex、再打開一次，這次 Select a project 選剛建好的 我的小隊。

    ⚠️ Windows 防呆：點「Select a project」彈出的「選擇資料夾」視窗只顯示資料夾、把檔案（如 AGENTS.md）藏起來。正常！確認選中 我的小隊，點右下角 「選擇資料夾」 即可。

  5. 確認畫面顯示 Local；對它說一句（咒語 1）：請先讀這個資料夾的 AGENTS.md，告訴我你的身分。 → 它會認出自己是領隊洄瀾，並印出專案資料夾路徑。

🛠️ 進階（會用終端機的人才需要）：也可以在 我的小隊 裡直接跑 codex。一般同學用桌面 app 就好。

Part B：讓領隊設計你的小隊

在 Codex（領隊洄瀾）裡，貼這句（複製 04 咒語 2），它會一題一題問你（名字、個性、想做什麼），幫你寫好 AGENTS.md 與人格檔，並把專案資料夾路徑印出來。

懶得想就每題答「都好」，用預設：領隊洄瀾、隊員太魯閣。

把「設計小隊」交給領隊問你，就是「讓 AI 幫你設定」的精神。

Part C：讓隊員就位（Antigravity 桌面版 開「同一個」專案資料夾）

這門課裡 Antigravity 是隊員太魯閣。

  1. 裝 Antigravity 桌面版：到 https://antigravity.google/download 下載安裝（認明桌面版，不是開發者 IDE 版）。
  2. 打開它，點「用 Google 帳號登入」（免費 Google 帳號就行，登入你自己來）。
  3. 在 Antigravity 裡打開剛剛那個一模一樣的專案資料夾（領隊在 Part A 印出來的 我的小隊）。
  4. 對它說一句：請先讀這個資料夾的 AGENTS.md，告訴我你的身分。 → 它會認出自己是隊員太魯閣。

🛠️ 進階：也可用 CLI——在 我的小隊 資料夾裡跑 agy --add-dir .。

Part D：開工！選一種模式，下第一個任務

你是小隊長。開工前，先跟領隊講要用哪種模式：

模式一：手動接力（預設，看得見每一棒）

  1. 跟領隊（Codex）說：這次用手動模式。幫我做一份花蓮一日遊景點清單，三個點各一句。拆好任務寫進 inbox 後叫我去請隊員。
  2. 領隊把任務寫進 inbox，叫你去找隊員。
  3. 你切到 Antigravity（隊員）：看 inbox 接任務、做完放 outbox、叫我回去找領隊。
  4. 你回到 Codex（領隊）：收 outbox、檢查、給我總結。

🎉 你剛當了一次小隊長，親手指揮兩個 AI 接力完成一件事——全程只動嘴、沒寫半行程式。

模式二：全自動（省事）

跟領隊說：這次用自動模式，幫我把整件事跑完、檢查好、直接回報我。

模式三（進階示範）：領隊用 Computer Use 自己跑完手動接力 ⭐

領隊（Codex）能用「電腦操作（Computer Use）」當你的雙手——自己切到隊員 Antigravity 的視窗、貼指令、再回收檢查，把手動接力自動演一遍給你看。做法見 04 咒語 9。

⚠️ 需要較新的 Windows／Mac；執行時它會接管你的滑鼠鍵盤、佔住前景（你會看著它自己動）。不是每台機器都跑得動，當示範用，不是基本盤。

兩三種都玩一次，感受差別：手動＝你掌控、看得見；自動＝快、交給 AI；Computer Use＝看 AI 替你動手。 這就是「要不要讓人插手」——AI 時代最重要的判斷之一。

📌 給 AI 與老師看的技術備註（學生可跳過）

這段給「幫忙設定的 AI」和老師看——把會影響順不順的細節一次講清。學生不必懂。

角色與環境 - 領隊洄瀾＝Codex（跑在 codex）；隊員太魯閣＝Antigravity（跑在 agy）。桌面為主：領隊用 Codex app「Select a project」開專案資料夾、隊員用 Antigravity 桌面版開同一個資料夾。CLI 是進階/備援。 - 兩個 agent 不直接對話，靠專案資料夾的 workspace/inbox、outbox、shared 傳檔；兩邊必須是同一個專案資料夾。 - 三種模式：手動接力（預設，agent 不互相直呼、棒子交回小隊長）、全自動、Computer Use 示範（進階）。

安裝與帳號 - 領隊 Codex：官方桌面 app＋VS Code/Cursor/Windsurf 擴充（app、ide），會在動工前讀 AGENTS.md（agents-md）。用 ChatGPT 帳號登入（各方案含免費都能用、只差用量）；校園 proxy 攔 TLS 可能讓 OAuth 失敗，課前在教室網路試一次。CLI 進階：Windows irm https://chatgpt.com/codex/install.ps1 | iex、Mac curl -fsSL https://chatgpt.com/codex/install.sh | sh。 - 隊員 Antigravity：桌面版（https://antigravity.google/download），任何 Google 帳號（含免費）登入。CLI 進階：Windows irm https://antigravity.google/cli/install.ps1 | iex、Mac curl -fsSL https://antigravity.google/cli/install.sh | bash（裝到使用者資料夾、免系統管理員）。 - 🪟 Windows 走 CLI 時：裝完任何 CLI 要把所有終端機關掉重開，PATH 才生效（用桌面 app 不會遇到）。

Computer Use（模式三，進階） - Codex app（v26.527 起）在 Windows 可「看畫面、點按鈕、打字」操作桌面程式（Computer Use 文件）。⚠️ Windows 上跑在使用中的桌面、不能背景跑，執行時接管前景滑鼠鍵盤；手機遠端管理那套要 Win11 build 26100＋NPU。所以核心課程不依賴它，只當示範。

AGENTS.md／身分 - codex 與 agy 都讀專案根目錄的 AGENTS.md，開機自動認身分（codex app 選那個資料夾、agy 桌面版開那個資料夾即可）。沒有用 .agents/ 子資料夾。 - 保險起見可叫 agent 第一句報到時「印出專案資料夾完整路徑」，確認兩邊同一個。

機制說明：兩個 agent 透過 inbox／outbox 互傳紙條的整條協作鏈，已驗證可正常運作。

給 AI 的指令包｜把事情交給 AI 做

用法：下面每段是一個「咒語」。整段複製，貼進你正在用的 AI（領隊洄瀾＝Codex、隊員太魯閣＝Antigravity，桌面 app 或終端機都行），按 Enter，請它幫你做。 咒語裡的「洄瀾／太魯閣」是預設名，你改過就跟著換。你（學生）＝小隊長。

咒語 0：請領隊把我的小隊裝起來（第一步，貼給剛裝好＋登入的 Codex）⭐

貼給領隊 Codex（這時它開在你的「桌面」當臨時工作區）。它會幫你下載教材、建好「我的小隊」。 桌面版 Antigravity 還是你自己裝（見指南 Part C），這條只負責把專案建好。

請幫我把這門課的「AI 雙人小隊」設定好，一步一步做、需要我決定時停下來問我：
1. 在我的桌面下載這門課教材：執行 gh repo clone cwstedctw/ai-agent-team-course
   （若我這台沒有 gh，改用 git clone https://github.com/cwstedctw/ai-agent-team-course.git，
    或先告訴我怎麼裝 gh）。
2. 進到下載好的資料夾，把裡面的「範本團隊」整包複製到我的桌面，改名為「我的小隊」。
3. 檢查我這台有沒有 Antigravity 的命令列 agy；沒有的話只要告訴我即可
   （桌面版 Antigravity 我會自己去 antigravity.google/download 裝，不用你裝）。
4. 把「我的小隊」資料夾的完整路徑印出來給我（等一下兩個 app 都要開這個資料夾）。
做完用白話告訴我下一步：關掉你、再打開、Select a project 選「我的小隊」。全程繁體中文台灣用語。

咒語 1：報到＋確認環境＋印出專案資料夾路徑

咒語 9：高階進階玩法——用 Computer Use 自動跑手動接力（演示手動模式自動化）⭐

貼給領隊洄瀾（Codex，支援 Computer Use／電腦操作）。 這條咒語示範讓領隊扮演「學生的雙手」，在手動模式下自己切換視窗、貼指令並完成完整的手動接力驗收！ ⚠️ 需要較新的 Windows／Mac；執行時會接管你的滑鼠鍵盤、佔住前景。當示範用，不是基本盤。

請用 Computer Use 幫我操作 Antigravity（隊員）視窗，完成一次手動接力流程。

分工：
- 你（領隊 Codex）：拆任務、寫派工紙條、最後檢查。
- 隊員 Antigravity：讀取派工紙條、完成成品、寫入 outbox。

任務主題：台北親子半日遊

流程：
1. 你先把任務拆好，寫入 workspace/inbox/task.md。
2. 你再用 Computer Use 操作 Antigravity 視窗，把以下指令貼進去並送出：
   「請讀取 workspace/inbox/task.md，照任務完成成品，放進 workspace/outbox/，並留下 workspace/outbox/handoff.md 交接說明。完成後請停下來，只回報『已完成，可請領隊檢查』。」
3. 等 Antigravity 完成後，你讀取 workspace/outbox 的成品與 handoff.md。
4. 你檢查成品是否符合 workspace/inbox/task.md 的規格。
5. 你最後把審查結果回報給我。

交付格式：Markdown 表格
表格欄位包含：時間、地點、附近捷運站、活動內容、適合年齡、雨天備案、資料來源

- workspace/outbox/handoff.md
