# 打造你的 AI 雙人小隊 — 通識課教材包

> 一套讓「完全不會寫程式」的大學通識生，也能在自己電腦上**養出兩個會合作的 AI 夥伴**的教材。
> 為**國立東華大學洄瀾學院通識教育中心**的課（例如「資訊科技與應用」）設計，可在學校 **Windows 電腦教室**或學生自帶的 **Mac 筆電**上做。
> 靈感來自陳文盛老師（Ted）的「洄瀾鏡像團隊」：洄瀾、立霧、秀姑巒三位 AI 手足共用一個資料夾、互留紙條、一起完成工作。學生版把它縮小成**兩個人**，名字與個性**由學生自己設計**。

## 三十秒看懂這堂課在幹嘛

1. 學生裝兩個**桌面 app**（滑鼠操作為主）：**Antigravity 桌面版（當領隊）** 與 **Codex app（當隊員）**，各用自己的 Google／ChatGPT 帳號登入，**兩個都打開「同一個專案資料夾」**。能交給 AI 做的安裝就交給領隊做。
2. 學生**自己設計**這兩個夥伴的名字、個性、專長（AI 會訪談你；不想花時間就用預設「洄瀾／太魯閣」）。
3. 它們**不直接講話**，而是透過那個**專案資料夾**互留紙條（領隊把任務寫進 `inbox/`，隊員把成品放進 `outbox/`）。
4. 學生當「**小隊長**」指揮小隊，可選**手動接力**（親手在兩個夥伴間傳棒、看得見每一棒）或**全自動**（只跟領隊講、其餘交給它）兩種模式。

學生學到的不是寫程式，而是 **「怎麼指揮一群 AI 一起工作」**——這是 2026 年的數位素養。

## 為什麼用 Antigravity ＋ Codex，不用 Claude？

學生版的雙人小隊用兩個工具，剛好對應老師團隊裡的兩位隊員：

- **領隊＝Google Antigravity（指令 `agy`，對應秀姑巒）**：任何 Google 帳號（含免費）就能登入，有中文，Windows／Mac 都能跑，Windows 裝在使用者資料夾、免系統管理員權限（電腦教室裝得起來）。
- **隊員＝OpenAI Codex（對應立霧）**：用你的 **ChatGPT 帳號登入**（瀏覽器點「Sign in with ChatGPT」，**不需要 API 金鑰**），擅長寫程式、查資料、快手任務。
- **不用 Claude Code**（洄瀾的引擎）：功能最強，但要付費訂閱，不適合全班人手一份。

> 兩個 agent 怎麼合作？靠**共用資料夾傳紙條**（inbox／outbox／shared），不是直接對話——這套機制已在 Mac 實測：領隊 agy 派工 → 隊員 codex 做 → 領隊收回檢查，全程打通。

## 老師最短上手路徑

1. 先自己照 `02_安裝設定指南.md` 跑一遍，**最好在電腦教室那台 Windows 機器上**實跑一次（Mac 與 Windows 有些差異，指南最後的技術備註有列）。
2. 上課投影片與課程網站（Claude Design 製）連結在 `slides/投影片與課程網頁.md`。
3. 課堂發 `01_學生講義.md` 給學生；卡關的同學丟 `04_給AI的指令包.md` 讓 AI 自救。
4. 評量、分組、電腦教室與帳號注意事項見 `03_教師手冊.md`。
5. ⚠️ 想讓學生的 AI 直接「讀 GitHub repo 幫忙裝」，**另開一個只放 `course_agent_team/` 的公開 repo**——本團隊主 repo 含私人記憶，不要整包公開。
