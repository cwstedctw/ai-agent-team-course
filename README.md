# 打造你的 AI 雙人小隊 — 通識課教材包

> 一套讓「完全不會寫程式」的大學通識生，也能在自己電腦上**養出兩個會合作的 AI 夥伴**的教材。
> 為**國立東華大學洄瀾學院通識教育中心**的課（例如「資訊科技與應用」）設計，可在學校 **Windows 電腦教室**或學生自帶的 **Mac 筆電**上做。
> 靈感來自陳文盛老師（Ted）的「洄瀾鏡像團隊」：洄瀾、立霧、秀姑巒、木瓜溪四位 AI 手足共用一個資料夾、互留紙條、一起完成工作。學生版把它縮小成**兩個人**，名字與個性**由學生自己設計**。

## 三十秒看懂這堂課在幹嘛

1. 學生裝兩個**桌面 app**（滑鼠操作為主）：**Codex app（當領隊）** 與 **Antigravity 桌面版（當隊員）**，各用自己的 ChatGPT／Google 帳號登入，**兩個都打開「同一個專案資料夾」**。
2. 學生**自己設計**這兩個夥伴的名字、個性、專長（AI 會訪談你；不想花時間就用預設「洄瀾／太魯閣」）。
3. 它們**不直接講話**，而是透過那個**專案資料夾**互留紙條（領隊把任務寫進 `inbox/`，隊員把成品放進 `outbox/`）。
4. 學生當「**小隊長**」指揮小隊，可選**手動接力**（親手在兩個夥伴間傳棒、看得見每一棒）或**全自動**（只跟領隊講、其餘交給它）兩種模式。

學生學到的不是寫程式，而是 **「怎麼指揮一群 AI 一起工作」**——這是 2026 年的數位素養。

## 為什麼用 Antigravity ＋ Codex，不用 Claude？

學生版的雙人小隊用兩個工具，剛好對應老師團隊裡的兩位隊員：

- **領隊＝OpenAI Codex**：用你的 **ChatGPT 帳號登入**，擅長拆任務、統籌、把關；而且會「**電腦操作（Computer Use）**」——進階時能當小隊長的雙手、自己驅動隊員的視窗（所以讓它當領隊）。
- **隊員＝Google Antigravity（指令 `agy`）**：任何 Google 帳號（含免費）就能登入，有中文，Windows／Mac 都能跑，負責實際動手做。
- **不用 Claude Code**（洄瀾的引擎）：功能最強，但要付費訂閱，不適合全班人手一份。

> 兩個 agent 怎麼合作？靠**共用資料夾傳紙條**（inbox／outbox／shared），不是直接對話——領隊 codex 派工 → 隊員 agy 做 → 領隊收回檢查。

## 老師最短上手路徑

1. 先自己照 `02_安裝設定指南.md` 跑一遍，**最好在電腦教室那台 Windows 機器上**實跑一次（Mac 與 Windows 有些差異，指南最後的技術備註有列）。
2. 上課投影片與課程網站（Claude Design 製）連結在 `slides/投影片與課程網頁.md`。
3. 給學生的主教材用**學生手冊 PDF**（`打造你的AI雙人小隊-學生手冊.pdf`），或請學生開[線上課程網站](https://cwstedctw.github.io/ndhu-ai-courses/)；卡關的同學把 `04_給AI的指令包.md` 裡對應的咒語貼給 AI 自救。
4. 評量、分組、電腦教室與帳號注意事項見 `03_教師手冊.md`。
5. 想讓學生的 AI 直接「讀 GitHub repo 幫忙裝」：本課教材**已放在公開 repo** [cwstedctw/ai-agent-team-course](https://github.com/cwstedctw/ai-agent-team-course)（只含課程內容、不含團隊私人記憶）；線上課程網站見 <https://cwstedctw.github.io/ndhu-ai-courses/>。⚠️ 別把團隊主 repo（含私人記憶）整包公開。
